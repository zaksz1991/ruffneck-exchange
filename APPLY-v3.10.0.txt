RUFFNECK EXCHANGE v3.10.0 — COMPLETE CUMULATIVE REPLACEMENT

This release is a complete cumulative replacement based on v3.9.1.

DEPLOY
1. Extract this ZIP.
2. Open the `ruffneck exchange` folder.
3. Replace the contents of the existing GitHub repository with the contents of this folder.
4. Commit the replacement to the `main` branch.
5. Allow Vercel to deploy.

SUPABASE
No new SQL migration is required. Keep the existing RuffNeck Entertainment project and migrations 001–028 unchanged. Do not rerun migrations.

VERCEL
No new environment variables are required. Keep the existing project settings and Root Directory `./`.

NEW FEATURE
Customer and supplier dashboards now show linked quotation revision timelines, compare version fields and disclose price/currency changes. This is based on the existing revision data from migration 028.

VALIDATION
Run the cumulative `npm run check` script in the deployment environment. Full TypeScript checking and the Next.js production build must be confirmed by Vercel. See `BUILD_STATUS.md` for checks performed in this workspace.
